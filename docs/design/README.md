# Open design notes

Proposals and undecided questions live here, **not** in `docs/ADR/`. A record only graduates to an
ADR once the owner has decided and there is evidence behind it (`AGENTS.md` §6).

Mark anything open with `AWAITING DECISION` so it is greppable, and mirror it in
`../handoff/CURRENT.md` §8 so the next worker sees it without having to browse.
